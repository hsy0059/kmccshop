### 3.1 项目引用关系


### 3.2 Ocelot 网关路由

ApiGateway 通过 `ocelot.json` 配置统一路由，当前共 **12 条** 通配符路由（`{everything}`），将前端请求转发到 8 个下游微服务。通配符模式覆盖了所有业务接口，包括 feedback（反馈）、errand（跑腿）、rider（骑手）、post（帖子）、secondhand（二手）、lostfound（失物招领）、advertisement（广告）等功能模块。

| 上游路径模板 | 下游服务 | 端口 |
|------|---------|------|
| /api/v1/user/{everything}、/api/v1/auth/{everything}、/api/v1/address/{everything}、/api/v1/file/{everything} | User.Service | 53222 |
| /api/v1/merchant/{everything}、/api/v1/product/{everything} | Merchant.Service | 53523 |
| /api/v1/order/{everything} | Order.Service | 53216 |
| /api/v1/delivery/{everything} | Delivery.Service | 53221 |
| /api/v1/campus/{everything} | Campus.Service | 53211 |
| /api/v1/social/{everything} | Social.Service | 53215 |
| /api/v1/wallet/{everything} | Wallet.Service | 53224 |
| /api/v1/coupon/{everything} | Coupon.Service | 53225 |

> 网关基址：`http://localhost:53517`。新增微服务或路由时，同步在 `ocelot.json` 的 `Routes` 数组中追加条目，并更新下游端口。

### 3.3 Docker 容器化部署

项目支持完整的 Docker 容器化部署，包含端口自动释放机制。

#### Docker 管理脚本

| 脚本 | 功能 |
|------|------|
| `docker-build.ps1` | 批量构建 9 个镜像（ApiGateway + 8 微服务） |
| `docker-start.ps1` | 端口释放 → 旧容器清理 → docker-compose up → 健康检查 |
| `docker-stop.ps1` | 停止所有 campus_* 容器 |
| `docker-logs.ps1` | 查看指定服务或全部服务日志 |

#### 端口自动释放（PortHelper.cs）

ApiGateway 启动前自动检测 53517/53514 端口占用并终止旧进程：

```csharp
// Program.cs
PortHelper.FreePortIfNeeded(53517, logger);
PortHelper.FreePortIfNeeded(53514, logger);
```

仅 `Development` 环境生效，通过 `IPGlobalProperties` 检测端口监听状态，`netstat -ano` 解析 PID。

#### 容器 HTTPS 适配

容器内无开发证书，通过环境变量检测跳过 HTTPS：

```csharp
app.Urls.Add("http://0.0.0.0:53517");
if (!Environment.GetEnvironmentVariables().Contains("DOTNET_RUNNING_IN_CONTAINER"))
    app.Urls.Add("https://0.0.0.0:53514");
```

#### Docker 网络通信

容器间通过 Docker DNS 解析服务名（如 `mysql`, `merchant.service`），`ocelot.docker.json` 中下游 Host 使用容器别名而非 `localhost`。

### 3.5 Controller 规范

```csharp
[ApiController]
[Route("api/v1/[controller]")]
public class YourController : ControllerBase
{
    private readonly YourDbContext _db;
    public YourController(YourDbContext db) { _db = db; }

    [HttpGet("list")]
    public async Task<IActionResult> List([FromQuery] PageRequest page)
    {
        var query = _db.YourEntities.AsQueryable();
        var total = await query.CountAsync();
        var list = await query.Skip((page.Page - 1) * page.PageSize).Take(page.PageSize).ToListAsync();
        return Ok(ApiResponse<PageResult<YourEntity>>.Success(
            PageResult<YourEntity>.Of(list, total, page.Page, page.PageSize)));
    }

    [HttpGet("{id}")]
    public async Task<IActionResult> Detail(long id)
    {
        var entity = await _db.YourEntities.FindAsync(id);
        if (entity == null) return Ok(ApiResponse.Error(404, "未找到"));
        return Ok(ApiResponse<YourEntity>.Success(entity));
    }

    [HttpPost]
    public async Task<IActionResult> Create([FromBody] YourRequest req) { ... }

    [HttpPut("{id}")]
    public async Task<IActionResult> Update(long id, [FromBody] YourRequest req) { ... }
}
```

#### 5.3.3 three.js mock 策略

jsdom 不支持 WebGL，无法直接运行 three.js。测试通过 `vi.mock('three', ...)` 将所有 three.js 类（Scene、PerspectiveCamera、WebGLRenderer、Mesh、Points、Raycaster 等）替换为简单 JS 对象，确保：
- 构造函数可被 `new` 调用（使用 `function` 声明 + `mockObj3D` 辅助）
- `WebGLRenderer` 返回真实 `<canvas>` 元素（`document.createElement('canvas')`）
- `dispose`、`setSize`、`render`、`setAttribute` 等方法为 `vi.fn()` 便于断言
- 常量（`AdditiveBlending`、`DoubleSide` 等）以数字值导出

admin 端额外提供可复用的 mock 模块 `src/test/three-mock.ts`（导出 `ThreeMock` 默认对象）。

## 8. 常见问题

### Q1: "dotnet build" 报错 ?
确保安装了 .NET 10.0 SDK。

### Q2: 数据库连接失败 ?
检查 `appsettings.json` 中的连接字符串，确保 MySQL Docker容器已启动。

### Q3: UniApp 编译报 "uni 不是内部命令" ?
运行 `npm install --legacy-peer-deps` 安装依赖。

### Q4: Android APK 打包失败 ?
需要安装 Android Studio 和 Android SDK，确保 JAVA_HOME 和 ANDROID_HOME 环境变量配置正确。

### Q5: 端口被占用 ?
修改对应服务的 `appsettings.json` 或 `Program.cs` 中的端口号。注意同步更新 ocelot.json 中的下游端口。
