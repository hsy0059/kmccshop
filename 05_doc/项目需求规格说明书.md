# 校园生活服务平台 — 项目需求规格说明书 (SRS)

## 1. 文档概述

| 文档版本 | 1.0.0 |
|---------|-------|
| 创建日期 | 2026-05-09 |
| 项目名称 | 校园生活服务平台 (Campus Life Service Platform) |

### 1.1 适用范围
本文档描述了校园生活服务平台的全部功能需求、非功能需求、接口需求及数据需求，作为后续设计、开发、测试的依据。

### 1.2 角色定义

| 角色 | 编码 | 说明 |
|------|------|------|
| 学生用户 | STUDENT | 平台核心使用者，可下单、发帖、交易 |
| 商家 | MERCHANT | 入驻商户，可管理商品、处理订单 |
| 骑手 | RIDER | 配送人员，负责外卖和跑腿配送 |
| 管理员 | ADMIN | 平台管理人员，负责审核、统计、系统管理 |

```
待支付(1) → 待接单(2) → 已接单(3) → 配送中(4) → 已送达(5) → 已完成(7)
                                           ↘ 已取消(6)
```

| F-ORD-007 | 订单统计 | 总订单数、总金额、今日订单、今日营收 |

#### 2.4.4 订单安全校验
| 编号 | 功能名称 | 说明 |
|------|---------|------|
| F-ORD-SEC-001 | 商品存在性校验 | 下单时校验商品 ID 是否存在，不存在返回 400 |
| F-ORD-SEC-002 | 商品归属校验 | 校验商品属于订单指定的商家，跨商家返回 400 |
| F-ORD-SEC-003 | 库存校验 | 校验商品库存 ≥ 购买数量，不足返回 400（含库存和需求量） |
| F-ORD-SEC-004 | 上架状态校验 | 商品 Status 必须为 1（上架），已下架返回 400 |
| F-ORD-SEC-005 | 价格防篡改 | 服务端使用数据库价格（优先 DiscountPrice）覆盖客户端传入价格 |

## 5. 接口需求

### 5.1 API概述
- 统一网关入口: `http://localhost:53517/api/v1/`
- 认证方式: Bearer Token (JWT)
- 数据格式: JSON
- 统一响应格式:

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

分页数据结构：
```json
{
  "code": 200,
  "data": {
    "list": [],
    "total": 100,
    "page": 1,
    "pageSize": 20
  }
}
```

## 6. 安全需求

| 安全项 | 需求描述 |
|-------|---------|
| 认证 | 所有API（除注册/登录）需Bearer Token认证 |
| 授权 | 基于用户角色（UserType）的接口访问控制 |
| 密码安全 | PBKDF2 HMACSHA256 100000迭代，128-bit salt |
| 敏感操作 | 提现、支付需二次确认密码 |
| 数据脱敏 | 手机号、身份证号于日志中脱敏处理 |
| 防攻击 | 短信验证码每分钟限1次/每IP日限10次 |
| 请求验证 | 输入参数类型及长度校验，Entity Framework参数化查询防SQL注入 |
